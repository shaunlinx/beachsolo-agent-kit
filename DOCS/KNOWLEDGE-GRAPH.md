# KNOWLEDGE-GRAPH · 考察点知识脉络系统（v9）

> 本文档定义：如何为每个考察点建独立文档、如何维护索引、如何在每次复盘中自动更新。
> 目标：用户复盘完全部卷子后，得到一份自己的完整知识复盘资产——冲刺时只需看考察点文档。

---

## 1. 系统结构

```
知识库「BeachSOLO 复盘」
├── 📌 学习资源索引（工具链接+优质视频）
├── 📌 考察点索引（按模块分类，每个考察点一个文档）
│   ├── 常识判断
│   │   ├── 成语辨析 → 考察点文档
│   │   ├── 十四五规划目标 → 考察点文档
│   │   └── ...
│   ├── 言语理解
│   ├── 数量关系
│   ├── 判断推理
│   └── 资料分析
├── 2021-福建-行测 复盘（每份卷子一个文档）
├── 2025-上海-行测 复盘
└── 多维表格「巩固任务」
```

## 2. 考察点文档模板（templates/knowledge-point.xml）

每个考察点一个独立云文档，结构：

```
标题：考察点名称（如"成语辨析：一蹴而就 vs 一挥而就"）

1. 定义与边界
   - 是什么（1-2句）
   - 不是什么（常见误解）
   - 适用场景

2. 易混点与相近词
   - 相近词辨析（表格：词/含义/区别/例句）
   - 反义词
   - 常见陷阱（出题人怎么干扰）

3. 权威来源
   - 原文链接（查证用，不作主要学习资源）
   - 出处说明

4. 相关真题
   - 卷子+题号+用户作答（对/错/蒙对/犹豫）
   - 每题的错因分析
   - 变式题（标准选择题）

5. 优质学习资源
   - 抖音/B站讲解视频（bookmark 卡片）
   - 工具链接

6. 我的笔记（用户自行补充）
   - 空白区域，用户可写文本/贴链接/插图片
   - 这是冲刺时的核心复习材料

7. 掌握状态
   - 未掌握 / 学习中 / 已掌握
   - 关联卷子数
   - 最后更新日期
```

## 3. 考察点索引文档（templates/knowledge-point-index.xml）

按模块分类，每个考察点一行：

| 模块 | 考察点 | 关联卷子数 | 掌握状态 | 文档链接 |
|---|---|---|---|---|
| 常识判断 | 成语辨析 | 3 | 学习中 | [打开](url) |
| 常识判断 | 十四五规划目标 | 1 | 未掌握 | [打开](url) |
| 言语理解 | 主旨概括题技巧 | 2 | 已掌握 | [打开](url) |

索引文档挂在知识库根目录，用户一眼看到所有考察点的掌握状态。

## 4. 每次复盘的更新流程

### 4.1 定位考察点
每道题（错题+蒙对题+犹豫题+稳对题）必须定位考察点：
- 从题目解析和题干提取核心考点
- 考察点粒度：具体到可独立成文的知识点（如"成语辨析"而不是"言语理解"）
- 同一考察点可能对应多道题

### 4.2 创建或更新
1. 查考察点索引文档，判断该考察点是否已有文档；
2. **已存在** → 更新文档：
   - 追加本题到"相关真题"（含作答状态+错因）
   - 追加新的易混点/相近词（如果本题涉及）
   - 追加优质视频到"优质学习资源"
   - 更新"掌握状态"和"关联卷子数"
3. **不存在** → 创建新文档（套模板），挂入知识库，更新索引文档；
4. 云文档每题链接到对应考察点文档（`<cite type="doc">`）。

### 4.3 用户笔记同步
- 云文档每题的"我的笔记"区，用户填写后，agent 在下一次复盘时
  把笔记同步到对应考察点文档的"我的笔记"区；
- 或者用户直接在考察点文档里写笔记（更直接）。

---

## 5. 冲刺复习时的使用方式

用户冲刺时：
1. 打开考察点索引文档，按"掌握状态"筛选"未掌握"和"学习中"；
2. 逐个打开考察点文档，重点看：
   - 易混点与相近词
   - 相关真题（自己错过的题）
   - 我的笔记（自己总结的要点）
3. 已掌握的考察点快速过一遍定义即可；
4. 不需要再看每份卷子的复盘文档——考察点文档已经汇总了所有相关内容。

---

## 6. 硬规则

1. **每道题必须定位考察点**，不允许"就题说题"不链接考察点；
2. **考察点文档必须挂入知识库**，不能只存在本地；
3. **索引文档必须实时更新**，新建考察点后立即追加到索引；
4. **用户笔记区必须留空白**，不要 agent 预填（那是用户的空间）；
5. **考察点粒度适中**：太粗（如"言语理解"）无意义，太细（如"某一道题的某个词"）无法复用；
6. **稳对题也要更新考察点文档**——追加对题记录和拓展内容（相近词/相关真题），
   这是"举一反三"的价值所在。
