# 交付物清单（九件套）与验收标准

> 每份数据包必须产出的标准化交付物。**任何一件缺失 = 交付不完整**。
> v10 起：核心分析由 deep-analysis.mjs 确定性产出（agent不重算）+ 全题四分类 + 考察点分级沉淀 + 分批交付。

|---|---|---|---|---|
| ① | **云文档带教档案（知识库节点）** | 最终沉淀载体：深度归因/模块画像/四分类/PPT/逐题带教(含考察点链接+视频+变式+笔记区)/巩固计划 | 飞书云文档 + 知识库节点 | 节点URL可打开；PPT bookmark+截图嵌入；每题有考察点链接+视频+变式+笔记区 |

## 云文档专项验收（交付①的硬门槛）

- [ ] 文档已挂入"BeachSOLO 复盘"知识库
- [ ] PPT 以 `<bookmark>` + `<img>` 截图嵌入
- [ ] 深度归因包含6个维度（用时/改答/蒙题/放弃/节奏/模块）
- [ ] 全题四分类表存在，蒙对题和犹豫题已带教
- [ ] 每题有考察点链接（`<cite type="doc">`）
- [ ] 每题至少1条抖音/B站讲解视频（bookmark，链接可达）
- [ ] 变式题为标准选择题（题干+4选项+答案+解析）
- [ ] 每题有"我的笔记"空白区（不预填）
- [ ] 巩固计划 D1-D3 为 checkbox

## PPT 专项验收（交付②的硬门槛）

- [ ] 设计系统：暖白底+勃垦第红+炭黑+赭石，思源宋体
- [ ] 页数动态 = N+3（N=需深度带教题数）
- [ ] 变式题是标准选择题（题干+4选项），不是填空题
- [ ] 逐页 lint 通过，回读页数一致
- [ ] 每页有 `<note>` 讲稿
- [ ] 不独立挂库、不独立交付

## 考察点文档专项验收（交付⑤的硬门槛）

- [ ] 每题已定位考察点（粒度适中，不粗不细）
- [ ] 首次出现的考察点已在复盘文档内联（不急于建独立文档）
- [ ] 符合升级条件（≥2份卷子出现或核心高频）的考察点已创建独立文档
- [ ] 独立文档包含：定义/易混点/相近词/权威来源/相关真题/笔记区
- [ ] 考察点索引文档已更新（新增或更新行）
- [ ] 已存在的考察点文档已追加本次记录（含稳对题的对题记录+拓展）
- [ ] 用户笔记区留空白

## 质量底线

- **深度可复核**：归因结论必须有数据依据（用时/改答/行为事件），不能凭感觉。
- **全题覆盖**：不只复盘错题，蒙对题和犹豫题必须带教，稳对题必须拓展。
- **知识沉淀**：每次复盘必须更新考察点文档，最终形成用户自己的知识资产。
- **速度**：分批交付（第一批5分钟内），总耗时20-30分钟，并行子agent。
- **可复现**：PPT用模板，考察点文档用模板，禁止现场手搓无模板的内容。
