# variants · 变式题库（按知识点索引）

> 本目录是"举一反三"的题源仓库。Agent 出变式题时**优先从本目录取题**（来源=真题/改编），
> 题库缺失才现场命题（来源=原创，且必须写入本目录，供后续会话复用）。
> 每题结构见 `schema` 说明；真实题目数据按知识点分文件存放。

## 结构

```
variants/
  README.md          # 本文件（检索说明）
  index.json         # 知识点 → 题目文件索引（Agent 先查这里）
  political-theory.json   # 政治理论/常识·政治类变式题
  verbal.json        # 言语理解类（待扩充）
  quantitative.json  # 数量关系/资料分析类（待扩充）
  ...
```

## 检索流程（Agent 执行）

1. 读 `index.json`，按 SKILL.md 步骤 3.1 判定的知识点匹配条目；
2. 命中 → 取对应题目（每题 1-3 道，优先标 `source: "真题"` 的）；
3. 未命中 → 现场命题（标 `source: "原创"`），用户判分后回写本目录；
4. 真题来源题目必须附出处字段（试卷/年份或权威来源 URL），不得标"真题"却无出处。

## 题目字段约定

```json
{
  "knowledgePoint": "政治理论·党的建设布局（政治建设摆在首位）",

  "difficulty": 1,
  "stem": "题干……",
  "options": { "A": "……", "B": "……", "C": "……", "D": "……" },
  "answer": "B",
  "explain": "解析：……（必须含正确项推理链 + 各错误项排除理由）"
}
```
